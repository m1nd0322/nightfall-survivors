# NIGHTFALL · 황혼의 생존자

V10.0 · ADAPTIVE SCORE

공개 플레이: https://m1nd0322.github.io/nightfall-survivors/

3명의 생존자와 10개의 밤을 돌파하는 설치 가능한 횡스크롤 생존 게임입니다. 이동·점프 외 공격은 자동입니다. 최종 클리어한 캐릭터의 성장과 보유 카드를 이 브라우저에 저장하고 다음 회차로 계승합니다.

## V10: 상황별 배경음악

외부 음원이나 라이브러리 없이 Web Audio로 생성하는 오리지널 4종 연주입니다. 같은 96 BPM·20초 화성 루프를 공유하며 약 2초 동안 교차 전환합니다.

| 상황 | 음악 |
|---|---|
| 체력 여유 + 적 적음 | 평화: 부드러운 패드, 느린 벨 선율 |
| 체력 여유 + 적 많음 | 긴장: 반복되는 짧은 음형과 타악 |
| 낮은 체력 + 적 많음 | 위급: 빠른 16분음표와 강한 저음 리듬 |
| 낮은 체력 + 적 적음 | 위기 완화: 하행 벨 선율과 부드러운 화음 |

- 체력 35% 이하에서 낮은 체력으로 판정하고 45% 이상에서 해제합니다. 주변 가로 550 월드 단위 안의 살아 있는 적을 세며, 8마리 이상에서 밀집으로 판정하고 4마리 이하에서 해제합니다. 보스 1마리는 위협 8로 계산합니다.
- 일반 전환은 1.5초 동안 같은 후보가 유지되고 이전 전환 후 2초 이상 지났을 때 시작합니다. 위급 진입은 즉시 2초 교차 전환을 시작합니다. 위기 완화는 체력 회복이나 무적을 의미하지 않습니다.
- 상단 **설정 → 상황별 BGM / 음악 볼륨**에서 켜기·음소거와 0~100% 볼륨을 조절합니다. 기본 볼륨은 22%입니다. 설정은 캐릭터·코인과 별도 키로 현재 브라우저에 보관합니다. 저장 실패 시 현재 탭에만 적용되었다고 알립니다.
- 자동 재생 정책 때문에 최초 캐릭터 선택·키 입력·터치 뒤 시작합니다. 선택 화면·일시정지·카드 선택·사망·스테이지 결과·다른 탭에서는 음량을 낮춰 멈춥니다. 기기가 오디오 재생을 중단하면 화면 입력으로 재개합니다.
- 처음 한 번 4개의 모노 PCM 루프를 나눠 생성하며, 이후 버퍼 4개만 반복 재생합니다. 버퍼 약 7MB, 22,050Hz이며 피크 제한을 적용합니다. 게임의 난수·진행·저장·전투 수치는 바꾸지 않습니다. 앱이 캐시된 후에는 음원 다운로드 없이 오프라인에서도 재생됩니다.
- 오디오 미지원·실패 시 안내하고 게임은 계속 동작합니다. 모바일 실제 기기의 무음 스위치·시스템 음량·브라우저 정책에 따라 소리가 차단될 수 있습니다.

## V9: 스테이지 준비 시간과 모바일 전용 화면

- 모든 스테이지의 실제 전투 시간 0~30초에는 그림자만 출현합니다. 소환 적도 같은 규칙을 적용합니다. 일시정지·카드 선택 중에는 시간이 흐르지 않습니다.
- 처치 목표를 30초 전에 달성하면 보스를 대기시키고, 30초가 되는 시점에 추가 처치 없이 한 번만 생성합니다. 30초 후에도 Lv.1~4의 일반 적은 그림자로 제한됩니다.
- PC는 기존 배율/레이아웃을 유지합니다. 터치 기기 또는 폭 700px 이하에서는 모바일 화면을 자동 사용합니다. 그래픽 설정의 화면 구성에서 자동/PC/모바일을 직접 선택할 수 있습니다.
- 모바일의 전투 시야는 최소 가로 720, 세로 360 월드 단위로 넓힙니다. 캐릭터와 적을 동일 배율로 축소하며 전투 수치·이동 속도·점프 물리·공격 범위는 바꾸지 않습니다. UI와 터치 버튼은 별도로 표시합니다.
- 모바일은 동적 화면 높이와 안전 영역을 적용하고 가로/세로 방향에 맞게 HUD를 압축합니다. 전투 캔버스 아래 64~76px는 이동·점프 버튼 전용 영역입니다. 모바일 캔버스 DPR은 1.5 이하, PC는 기존 2 이하이며 WebGPU 출력 예산과 Canvas 2D 대체 렌더러를 유지합니다.
- 방향키와 점프 버튼의 텍스트 선택, iOS 터치 콜아웃, 컨텍스트 메뉴와 드래그를 차단합니다. 페이지 전체의 확대나 다른 텍스트 선택은 막지 않습니다. 동시 이동·점프, 포인터 취소/캡처 해제, 일시정지·화면 회전 후 입력 초기화를 처리합니다.
- 기존 캐릭터 저장, 코인과 구매 내역의 저장 구조는 변경하지 않습니다.

## V8: 고정된 스테이지 난이도와 영구 상점
- 새 1회차의 첫 스테이지 적은 Lv.1입니다. 스테이지 안에서는 캐릭터 레벨업과 처치 수로 적 레벨이 변하지 않습니다.
- 클리어 보상 XP까지 적용한 뒤 다음 스테이지에 입장할 때 캐릭터 레벨을 한 번 캡처합니다. 저장된 캐릭터의 다음 회차도 복원한 레벨로 시작합니다.
- 캐릭터 Lv.1~4의 일반 출현/소환 적은 그림자만 등장합니다. Lv.5부터 A~F 특수·공중 적이 해금되지만 V9의 스테이지 첫 30초 제한을 우선 적용합니다.
- 레벨업·상자 카드는 1/2/3 또는 숫자패드로 즉시 선택하고, ←/→와 Enter/Space로 선택할 수도 있습니다. 키를 계속 눌러도 다음 보상까지 자동으로 소비하지 않습니다.
- 실제 적 100처치마다 코인 1개를 지급합니다. 보스도 포함되며 동일 적은 중복 집계하지 않습니다. 스테이지를 넘어가도 처치 진행은 유지되지만 새 플레이(새 회차/재도전)를 시작하면 100 미만의 잔여 처치 진행은 초기화됩니다.
- 받은 코인과 상점 영구 강화는 사망, 캐릭터 선택, 새로고침 후에도 유지됩니다. 클리어 저장과 별개로 지급/구매 시 저장합니다.
- 모든 캐릭터의 다음 플레이에 영구 강화를 적용합니다. 저장 캐릭터는 이미 반영된 강화에 새로 구매한 차이만 더하며, 기존 V7 저장본도 읽을 수 있습니다.
- 아래 가격은 매회 동일하며 각 아이템은 최대 10회 구매할 수 있습니다. 잔액 부족/최대 강화/저장 실패에서는 구매할 수 없으며, 잔액과 강화 내역은 하나의 IndexedDB 트랜잭션으로 함께 기록합니다. 여러 탭의 동시 구매도 음수 잔액을 만들지 않습니다.

|아이템|영구 효과|가격|
|---|---|---|
|생명의 목걸이|최대 HP 및 시작 HP +10|3코인|
|월광 숫돌|물리공격력 기본값 +2|3코인|
|별빛 수정|마법공격력 기본값 +2|3코인|
|파수꾼의 갑옷|방어력 +1|4코인|
|새벽의 장화|이동속도 +5|2코인|

저장 오류가 발생하면 기존 잔액/강화를 보호하고 미지급 코인을 현재 탭에서 재시도 대기로 보관합니다. 오류 안내가 있으면 창을 닫기 전에 상점의 저장 재시도를 사용하세요. 코인·상점은 IndexedDB, 클리어 캐릭터는 localStorage에 보관되며 서버/기기 간 동기화는 없습니다. 브라우저/앱 데이터를 삭제하면 저장도 소실됩니다.

## 움직이는 캐릭터와 회차 저장
- 선택 카드에 기사·사냥꾼·마법사 인물 애니메이션을 표시합니다. 외부 파일 없이 SVG/CSS로 동작하며 ‘동작 줄이기’ 설정을 존중합니다.
- 10번째 보스를 처치하고 남은 레벨업/상자 보상을 모두 선택한 뒤 캐릭터별 최신 클리어 저장본을 갱신합니다.
- 레벨, XP, HP/최대 HP, 보호막, 물리/마법 성장, 이동/공격 속도, 각 능력치와 보유 카드(중복 강화 포함)를 저장합니다. 누적 처치/플레이 시간도 계승합니다.
- 선택 화면의 ‘저장된 캐릭터’ 또는 승리 화면에서 다음 회차를 시작합니다. 첫 스테이지부터 시작하되 저장된 성장/HP/보호막을 그대로 복원합니다. 위치, 적, 탄환, 상태 이상, 공격 동작/재사용 대기, 스테이지 처치/시간은 초기화합니다.
- 한 번에 출현하는 적의 수가 회차마다 2마리씩 증가합니다. 2회차 +2, 3회차 +4, 4회차 +6입니다. 출현 간격/보스 규칙과 동시 적 110마리 안전 상한은 유지합니다. 상한에 도달한 경우 실제 생성 수는 제한됩니다.
- 다음 회차에서 죽거나 종료하면 그 도전 중 새로 얻은 미저장 성장만 잃습니다. 마지막 최종 클리어 저장본과 다음 도전 회차는 유지됩니다. 재도전할 때마다 회차가 올라가지는 않습니다.
- 새 1회차 시작은 저장본을 지우지 않습니다. 같은 캐릭터로 다시 최종 클리어하면 그 시점의 최신 상태가 저장본을 교체합니다. 다른 캐릭터의 저장본은 유지합니다.
- 캐릭터마다 독립적인 키에 원자적으로 저장하므로 다른 캐릭터의 동시 저장을 덮어쓰지 않습니다. 동일 캐릭터는 마지막으로 기록한 클리어가 우선합니다. 저장은 localStorage 기반이며 서버/계정/다른 기기로 동기화하지 않습니다. 브라우저 데이터 삭제, 시크릿 창 종료, 앱/브라우저 저장 공간 삭제 시 소실될 수 있습니다.
- 저장 실패 시 기존 저장을 보존하고 실패 안내/재시도 버튼을 표시합니다. 새 클리어본은 현재 탭의 메모리에만 임시 보관되므로 탭을 닫기 전에 재시도해야 합니다. 손상된 저장은 자동 덮어쓰지 않습니다.
- 디버그 테스트는 일반 플레이와 별도 저장 키를 사용합니다.

## 유지되는 전투 시스템
- 레벨업 필요 XP: Lv.1 18, Lv.2 36, Lv.3 72, Lv.4 144, Lv.5 288… 매 레벨 2배. 공식은 `18 × 2^(현재 레벨−1)`. 초과 XP는 다음 레벨로 이월됩니다.
- 적의 기본 레벨은 스테이지 시작 시 고정됩니다. 이미 전투 중인 적의 HP/레벨은 변하지 않습니다.
- 성장 카드 24종 → 40종. 레벨업과 보물상자 모두 3장 중 하나를 선택합니다. 여러 보상이 겹치면 차례대로 선택합니다. 마지막 보스 처치 때도 남은 보상을 모두 선택한 뒤 승리 화면으로 넘어갑니다.
- 스테이지 이름에 맞는 10개 배경과 바닥, WebGPU 안개/입자 색상을 적용했습니다.

## 적 성장과 스테이지
- 일반·특수·공중 적은 현재 스테이지 시작 시 고정한 레벨을 사용합니다. 이전의 처치 수 기반 추가 레벨 해금은 제거했습니다.
- 보스 레벨은 max(스테이지 번호, 시작 시 고정 레벨)입니다. 스테이지 도중 캐릭터가 성장해도 보스의 캐릭터 비례 부분은 변하지 않습니다.
- 출현 시 고정 레벨에 따라 HP/공격력/방어력을 계산합니다. A는 장갑, B는 투사체, C는 자폭, D는 저주, E/F는 비행 적입니다.
- 보스 출현 목표는 100,120,140,160,180,200,220,240,260,280처치입니다.
- 스테이지 안에서 20초마다 증원이 강화됩니다. 다음 회차의 추가 출현 수는 2회차 +2, 3회차 +4…입니다. 공중 적과 비행 보스는 점프로 공격 가능한 높이에 있습니다.

## 조작과 앱 설치
- A/D 또는 ←/→ 이동, W/↑/Space 점프, P/Esc 일시정지. 터치 버튼도 제공합니다.
- 상단 ‘그래픽’: 자동/WebGPU/Canvas 2D, 고화질/균형/절약, 효과별 켜기/끄기.
- Chrome/Edge의 ‘앱 설치’, iOS Safari의 공유 → 홈 화면에 추가로 설치합니다.
- 첫 온라인 실행 후 앱 파일의 캐시 준비가 끝나면 오프라인 실행이 가능합니다. 앱 파일 캐시와 클리어 저장본(localStorage)은 별도로 관리됩니다.
- 업데이트된 앱을 열려면 진행 중인 게임을 마친 뒤 새로고침하세요. 새로고침/종료/사망 시 진행 중인 도전은 초기화되지만 최종 클리어 저장본은 유지됩니다.

## 렌더러와 배포
Canvas 2D 원본 그림 + WebGPU 효과 합성의 하이브리드입니다. 3D 또는 전체 GPU 시뮬레이션은 아닙니다. HDR 블룸, 최대 48개 동적 광원, 안개/빛줄기, 인스턴스 입자를 WGSL로 처리합니다. 기본 5패스이며 출력 픽셀 예산은 고화질 260만, 균형 140만, 절약 65만입니다.

HTTPS/localhost에서 지원되는 경우 WebGPU를 사용하며, 미지원·초기화 실패·장치 중단·GPU 오류에서는 Canvas 2D로 자동 전환합니다. 그래픽 설정에서 WebGPU를 다시 선택하면 재시도합니다. 그래픽 전환은 진행을 초기화하지 않습니다. 외부 이미지·라이브러리·폰트·광고·분석 도구는 없습니다. 모든 배경과 셰이더는 HTML에 포함되어 있습니다.

GitHub Pages main/root로 배포합니다. 서비스 워커 캐시는 `nightfall-v10.0-`이며 과거 앱 캐시를 갱신합니다.

## 검사 범위

V10은 두 렌더러의 게임/BGM 검사 553개씩과 렌더러 29개·호환성 11개를 합쳐 1,146개 자동 검사를 통과했습니다. 네 가지 음악의 PCM 비영점 출력·피크·루프 경계·서로 다른 파형, 체력/적 수 경계와 완충 구간을 확인했습니다. 실제 브라우저 입력으로 오디오 활성화, 네 분위기의 출력 신호, 일시정지/카드 선택 시 정지, 중단 후 재개, 미지원 후 재시도, 음소거/볼륨의 새로고침 복원을 추가 확인했습니다. 서버가 응답하지 않는 상태에서도 390px 모바일 레이아웃에서 BGM이 생성·재생되고 설정 창이 화면 안에 맞는 것을 확인했습니다. 청감 품질과 실제 iOS/Android 기기의 재생 정책은 별도 확인이 필요합니다.
V9은 PC 크기의 WebGPU/Canvas 2D 회귀 검사와 렌더러/복구 검사를 합쳐 1,070개, 390px 모바일 크기의 두 렌더러에서 84개를 추가해 총 1,154개 자동 검사를 통과했습니다. 320×568, 360×640, 390×844, 430×932, 667×375, 844×390, 1024×768의 7개 화면에서 가로/세로 넘침, 버튼 크기/위치, 전투 영역 분리와 최소 시야를 확인했습니다. 가로·세로 모바일 WebGPU 픽셀 출력과 오프라인 V9 캐시 실행도 확인했습니다. 모바일 화면 검사는 데스크톱 브라우저의 동일 출처 iframe으로 재현한 것으로 실제 iOS/Android 기기 검증을 대체하지 않습니다. 기존 처치 기반 레벨 상승 검사는 새 스테이지 고정 규칙에 맞게 교체했습니다. 실제 방향키·Enter·Space 입력, 실제 상점 버튼의 3→0코인 차감, 사망/새로고침 후 코인 유지, 두 브라우저 컨텍스트의 동시 구매 잔액 보호, 390px 화면의 상점 레이아웃을 별도로 확인했습니다. 서버 연결 실패 상태에서도 코인·강화 복원, 구매 및 재실행 후 유지가 동작했습니다.

XP 경계·이월·사망 초기화, 스테이지 고정 레벨과 보스 성장, 40종 카드 및 새 보조 공격, 상자/레벨 보상 큐, 10개 배경의 서로 다른 픽셀, 기존 전투/비행/증원, WebGPU 픽셀 출력/전환/오류 복구를 검사합니다. 실제 모바일 기기, 전체 10스테이지 수동 완주, 장시간 발열/배터리/FPS, 난이도 밸런스는 별도 검증이 필요합니다.

개발용 `?debug=1`은 게임 상태 변형과 GPU 픽셀 읽기 검사 API를 활성화합니다. 디버그 저장은 별도 키에만 기록합니다. 일반 실행에서는 조회 및 그래픽 설정 API만 제공됩니다. `getXPRequirement()`, `getLevelDistribution()`, `getStageTheme()`, `getCombatStats()`, `getCatalog()`, `getRenderingInfo()`로 현재 규칙을 확인할 수 있습니다. `getEconomy()`, `getShopCatalog()`, `getSavedCharacters()`와 `getSaveStatus()`는 방어적 복사본과 저장 상태를 조회합니다.
