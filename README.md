# NIGHTFALL · 황혼의 생존자

설치 없이 브라우저에서 즐기는 횡스크롤 생존 게임입니다.

- 캐릭터 3종, 자동 공격, 점프/좌우 이동
- 24종 성장 카드와 보물상자
- 시간에 따라 강해지는 적 증원
- A~D 지상 특수 적, 박쥐/하피 공중 적
- 고유 외형/패턴을 가진 보스 10종, 비행 보스 4종
- 사망 시 초기화, 진행 저장 없음

## 조작
A/D 또는 ←/→ 이동, W/↑/Space 점프, P/Esc 일시정지. 터치 버튼도 제공합니다.

## 앱 설치
Chrome/Edge에서 앱 설치 버튼을 누르거나 iOS Safari의 공유 → 홈 화면에 추가를 사용하세요.
첫 실행과 서비스 워커 캐시 준비 후 오프라인으로도 실행할 수 있습니다. 오프라인 캐시는 게임 파일용이며 플레이 진행을 저장하지 않습니다.

## 구성
HTML Canvas + JavaScript. 외부 라이브러리/폰트/광고/분석 도구 없음.
GitHub Pages에서 main 브랜치의 루트 폴더를 배포하면 됩니다.

싱글 플레이 프로토타입이며 모바일 실기기 및 난이도 밸런스는 추가 조정 중입니다.

## v4.0: 처치 수 진행과 캐릭터 능력치
- 보스 목표: 스테이지 1~10에서 100,120,140,160,180,200,220,240,260,280마리.
- 스테이지별 0~20처치 구간에는 모든 지상/공중 일반·특수 적이 Lv.1입니다.
- 21·41·61…처치부터 Lv.2·3·4…를 해금합니다. 다음 스테이지에서 다시 초기화합니다.
- 레벨 L의 추첨 가중치는 1/L이며, 해금된 레벨들의 가중치를 정규화합니다.
- Lv.n+1의 빈도는 Lv.n보다 100/(n+1)% 낮습니다. 수식 기준으로 Lv.3은 Lv.2보다 33.3% 낮습니다.
- 21~40킬: Lv.1 66.7%, Lv.2 33.3%. 41~60킬: Lv.1 54.5%, Lv.2 27.3%, Lv.3 18.2%.
- HUD에 현재 방어력, 물리공격력, 마법공격력, 이동속도(px/s), 공격속도(회/s)를 표시합니다.
- 강화/저주가 능력치에 반영됩니다. 표시는 치명타·스킬배율·적 방어 적용 전 수치입니다.
- 기사와 사냥꾼의 고유 공격은 물리, 마법사의 고유 공격은 마법입니다. 보조 마법은 카드 기본 피해에 현재 마법공격력/1레벨 기본 마법공격력 비율을 적용합니다.
