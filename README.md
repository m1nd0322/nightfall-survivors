# NIGHTFALL · 황혼의 생존자

설치 없이 브라우저에서 즐기는 횡스크롤 생존 게임입니다.

- 캐릭터 3종, 자동 공격, 점프/좌우 이동
- 24종 성장 카드와 보물상자
- 시간에 따라 강해지는 적 증원
- A~D 지상 특수 적, 박쥐/하피 공중 적
- 고유 외형/패턴을 가진 보스 10종, 비행 보스 4종
- 사망 시 초기화, 진행 저장 없음

## 조작
A/D 또는 ←/→ 이동, W/↑/Space 점프, P/Esc 일시정지. 터치 버튼도 제공합니다.

## 앱 설치
Chrome/Edge에서 앱 설치 버튼을 누르거나 iOS Safari의 공유 → 홈 화면에 추가를 사용하세요.
첫 실행과 서비스 워커 캐시 준비 후 오프라인으로도 실행할 수 있습니다. 오프라인 캐시는 게임 파일용이며 플레이 진행을 저장하지 않습니다.

## 구성
HTML Canvas + JavaScript. 외부 라이브러리/폰트/광고/분석 도구 없음.
GitHub Pages에서 main 브랜치의 루트 폴더를 배포하면 됩니다.

싱글 플레이 프로토타입이며 모바일 실기기 및 난이도 밸런스는 추가 조정 중입니다.

## v4.0: 처치 수 진행과 캐릭터 능력치
- 보스 목표: 스테이지 1~10에서 100,120,140,160,180,200,220,240,260,280마리.
- 스테이지별 0~20처치 구간에는 모든 지상/공중 일반·특수 적이 Lv.1입니다.
- 21·41·61…처치부터 Lv.2·3·4…를 해금합니다. 다음 스테이지에서 다시 초기화합니다.
- 레벨 L의 추첨 가중치는 1/L이며, 해금된 레벨들의 가중치를 정규화합니다.
- Lv.n+1의 빈도는 Lv.n보다 100/(n+1)% 낮습니다. 수식 기준으로 Lv.3은 Lv.2보다 33.3% 낮습니다.
- 21~40킬: Lv.1 66.7%, Lv.2 33.3%. 41~60킬: Lv.1 54.5%, Lv.2 27.3%, Lv.3 18.2%.
- HUD에 현재 방어력, 물리공격력, 마법공격력, 이동속도(px/s), 공격속도(회/s)를 표시합니다.
- 강화/저주가 능력치에 반영됩니다. 표시는 치명타·스킬배율·적 방어 적용 전 수치입니다.
- 기사와 사냥꾼의 고유 공격은 물리, 마법사의 고유 공격은 마법입니다. 보조 마법은 카드 기본 피해에 현재 마법공격력/1레벨 기본 마법공격력 비율을 적용합니다.

공개 플레이: https://m1nd0322.github.io/nightfall-survivors/


## v5.0: WebGPU LIGHT
- 기존 Canvas 2D 원본 그림과 CPU 게임 로직을 유지하고, WebGPU로 화면 합성과 추가 효과를 처리하는 하이브리드 렌더러입니다. 3D 게임이나 전체 GPU 시뮬레이션으로 변경한 것은 아닙니다.
- WGSL 셰이더: 밝은 영역 추출 → 수평/수직 HDR 블룸 → 광원·안개·빛줄기·색상 합성 → 인스턴스 입자. 기본 5개 렌더 패스입니다.
- 마법탄/적 탄환/공격/보스/상자/경험치의 위치에 따라 최대 48개 동적 광원을 합성합니다.
- GPU가 전투 불꽃과 떠다니는 입자를 인스턴스 사각형으로 그립니다. 저해상도 rgba16float 블룸 버퍼를 사용합니다.
- 상단 그래픽 버튼: 자동/WebGPU/Canvas 2D, 고화질/균형/절약, 효과별 켜기/끄기. 선택한 시각 효과는 게임 규칙과 진행을 바꾸지 않습니다.
- 출력 픽셀 예산은 고화질 260만, 균형 140만, 절약 65만입니다. Canvas 원본과 게임 HUD는 기존 구조를 유지합니다.
- HTTPS 또는 localhost에서 WebGPU가 사용 가능한 경우 활성화됩니다. 미지원·어댑터/장치 초기화 실패·장치 중단·GPU 오류 시 Canvas 2D로 자동 전환합니다. GPU 장치 중단 후 그래픽 설정에서 WebGPU를 선택하면 다시 시도합니다.
- 그래픽 모드와 품질 전환, GPU 장치 중단은 진행을 초기화하지 않습니다. 페이지 새로고침/종료/사망 시 진행이 초기화되는 기존 규칙은 그대로입니다.
- 셰이더는 HTML 안에 포함되어 추가 다운로드가 없습니다. 서비스 워커 캐시는 v5.0이며 진행 상태는 저장하지 않습니다.

### 검증 범위
- 기존 게임 검사 311개를 WebGPU/Canvas 2D 양쪽에서 실행하고, 렌더러 검사 29개를 추가했습니다: 자동 폴백·오류 복구·자원 정리 검사 11개를 포함해 합계 662개 통과.
- 실제 GPU 텍스처의 픽셀 읽기, 효과 켜기/끄기에 따른 픽셀 변화, 화면 크기 변경, 모드/품질 전환, 장치 중단과 재초기화를 검사했습니다.
- 의도적으로 주입한 GPU 오류를 제외하고, 셰이더 및 JavaScript 오류는 기록되지 않았습니다. 모바일 실기기, 모든 GPU/브라우저, 장시간 발열/배터리/FPS 성능은 검증하지 않았습니다. GPU 합성 효과를 추가한 것으로, 기존 버전보다 항상 빨라진다는 보장은 없습니다.

### 개발용 검사
?debug=1에서 renderer-tests.js 및 기존 검사 스크립트를 실행할 수 있습니다.
상시 API: getRenderingInfo(), setRenderingMode('auto'|'webgpu'|'canvas2d'), setRenderingQuality('high'|'balanced'|'low'), setRenderingEffects({bloom,lights,fog,particles}).
디버그 전용: sampleGpuFrame(), loseGpuDevice(). getRenderingInfo().lastSubmitCpuMs는 CPU 명령 제출 시간이며 GPU 프레임 시간/FPS가 아닙니다.
